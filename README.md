# Portfolio — Enzo Hillairet

Portfolio d'étudiant BUT MMI (parcours Com & UX). Site : https://enzoh.fr

## Technologies déclarées
- **Astro** : génère un site statique (HTML/CSS, très peu de JavaScript).
- **Tailwind CSS** (v4) : outil de style, adapté à ma direction artistique (variables de couleurs, polices et effets de verre définis par moi). Aucun thème ni template prédéfini.

## Polices (hébergées dans le projet, via les paquets npm Fontsource)
- **Inter** (400, 600) : SIL Open Font License 1.1.
- **Unbounded** (900) : SIL Open Font License 1.1, © The Unbounded Project Authors.

Le texte de la licence est fourni dans `node_modules/@fontsource/*/LICENSE`.

## Lancer le projet
```
npm install
npm run dev      # serveur local
npm run build    # génère le dossier dist/ à mettre en ligne
```

## Autres fichiers à lire
- `IA.md` : déclaration d'usage de l'IA.
- `QUALITE.md` : contrôles accessibilité, performance, référencement, conformité juridique.
